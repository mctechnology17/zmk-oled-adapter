How the versions work (the third number is the ZMK version):
- v0.0.3.N        versions for ZMK v0.3 (branch `zmk-v0.3`, and `main` while it is on ZMK v0.3)
- v0.0.4.N        versions for the next ZMK version (v0.4)
- New work is developed on the branch `dev`

# FEATURES v0.0.3 (Nov 18, 2026) · ZMK v0.3
=======================================
First tagged version: snapshot of everything published until this date. Build verified with ZMK v0.3.

# NEW FEATURES
- [x] Adapter shields for 128x32, 128x64 and 128x128 OLED screens without modifying the keyboard shield
- [x] Pro Micro pinout: `oled_adapter_pro_micro_128x32`, `oled_adapter_pro_micro_128x64`, `oled_adapter_pro_micro_128x128`
- [x] Seeeduino XIAO BLE pinout: `oled_adapter_seeeduino_xiao_ble_128x32`, `oled_adapter_seeeduino_xiao_ble_128x64`, `oled_adapter_seeeduino_xiao_ble_128x128`
- [x] The `oled` node is created from scratch, so it also works when the keyboard shield has no `oled` node (Nov 09, 2025)
